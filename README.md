# Kian Fanavaran Negah Download Manager (KFNDM)

<div dir="rtl" align="right">

**دانلود منیجر حرفه‌ای و اشتراکی «کیان فناوران نگاه»** — اکوسیستم یکپارچه شامل اپلیکیشن دسکتاپ پرسرعت (۳۲ اتصال هم‌زمان + دانلودر ویدیوی 8K/4K از تمام سایت‌ها)، افزونه اختصاصی مرورگر و وب‌پورتال مدیریت اشتراک و امنیت ضدکرک.

📄 **[مشاهده سند کامل معماری، سیستم دیزاین و جزئیات فنی (`docs/ARCHITECTURE_AND_ROADMAP.md`)](docs/ARCHITECTURE_AND_ROADMAP.md)**

---

## اجزای معماری اکوسیستم (Monorepo)

| بخش | مسیر هدف | شرح مسئولیت |
| :--- | :--- | :--- |
| **اپلیکیشن دسکتاپ** | `apps/desktop` | اپ دسکتاپ کراس‌پلتفرم (ویندوز و مک) با رابط تیره مدرن (`#13131A` و گرادیان فیروزه‌ای-بنفش)، موتور دانلود ۳۲ تکه‌ای، دانلود ویدیو (`yt-dlp` + `ffmpeg`)، قفل سخت‌افزاری (HWID) و گیت بررسی اشتراک پیش از هر دانلود |
| **سایت و سرور لایسنس** | `apps/web-portal` | لندینگ‌پیج فروش، پنل مشترکین، پنل مدیریت ادمین، مدیریت پلن‌ها و کدهای لایسنس، و اندپوینت صدور مجوز رمزنگاری‌شده (`Ed25519 Signed Lease`) برای هر دانلود |
| **افزونه مرورگر** | `apps/extension` | افزونه اختصاصی Chrome / Edge / Brave برای رهگیری خودکار لینک‌ها، ارسال امن کوکی‌های نشست و شکار ویدیوهای وب و استریم‌های HLS/DASH |
| **پروتکل مشترک** | `packages/license-protocol` | اسکیمای مشترک توکن‌ها، امضای دیجیتال نامتقارن `Ed25519` و قراردادهای امنیتی بین سرور و کلاینت |

## نقشه راه فازبندی‌شده و مأموریت‌های هر فاز

### فاز ۱ — زیرساخت Monorepo، پروتکل رمزنگاری و سایت لایسنس (`web-portal`)
- [ ] **مأموریت ۱.۱:** راه‌اندازی `npm workspaces` و ساخت پکیج `packages/license-protocol` (امضای دیجیتال `Ed25519`، ساختار `Nonce` و توکن مجوز دانلود).
- [ ] **مأموریت ۱.۲:** پیاده‌سازی دیتابیس مشترکین، پلن‌ها، کلیدهای لایسنس (`LicenseKey`)، دستگاه‌های متصل (`DeviceHwid`)، پرداخت‌ها و لاگ ممیزی دانلودها.
- [ ] **مأموریت ۱.۳:** پیاده‌سازی API امن دسکتاپ شامل ورود با ثبت HWID، استعلام نشست، فعال‌سازی کد لایسنس و اندپوینت حیاتی `POST /api/v1/license/authorize-download` (صدور مجوز امضاشده پیش از هر دانلود).
- [ ] **مأموریت ۱.۴:** طراحی و ساخت لندینگ‌پیج فروش، صفحات احراز هویت، خرید آنلاین اشتراک و داشبورد کاربری با سیستم دیزاین تیره و گرادیان فیروزه‌ای-بنفش.
- [ ] **مأموریت ۱.۵:** ساخت پنل مدیریت ادمین (مدیریت کاربران و پلن‌ها، تولید لایسنس‌کی، مسدودسازی آنی، لاگ زنده دانلودها و کنترل نسخه اجباری اپ).
- [ ] **مأموریت ۱.۶:** نوشتن تست‌های یکپارچگی کامل چرخه اشتراک، قفل سخت‌افزاری و صدور/رد مجوز دانلود.

### فاز ۲ — هسته اپ دسکتاپ، برندینگ مستقل و پیاده‌سازی کامل سیستم دیزاین (`desktop`)
- [ ] **مأموریت ۲.۱:** راه‌اندازی ساختار مستقل Electron با شناسه `com.kianfanavarannegah.kfndm`، پورت لوکال اختصاصی و آیکون‌های رسمی برند.
- [ ] **مأموریت ۲.۲:** یکپارچه‌سازی موتور دانلود ۳۲ تکه‌ای با الگوریتم Work-Stealing، توقف/ادامه، تعویض لینک منقضی‌شده، محدودساز سرعت، پراکسی، صف‌ها (`Queues`) و زمان‌بند (`Scheduler`).
- [ ] **مأموریت ۲.۳:** پیاده‌سازی دقیق پنجره بدون فریم مطابق طرح مرجع (`#13131A`)، نوار عنوان سفارشی، نوار منو و جست‌وجو، فیلد سریع `Add Url` با دکمه بنفش دانلود، نوار ابزار ۹ دکمه‌ای و جدول دانلودها با نوار پیشرفت گرادیانی.
- [ ] **مأموریت ۲.۴:** ساخت درخت دسته‌بندی آکاردئونی سایدبار، ویجت گرافیکی نیم‌دایره‌ای `Disk Space` و دکمه `Disk Cleaner`، منوی راست‌کلیک شناور ۱۱ گزینه‌ای و فوتر سرعت زنده و `Speed Test`.
- [ ] **مأموریت ۲.۵:** پیاده‌سازی پشتیبانی دوزبانه کامل (انگلیسی LTR پیش‌فرض + فارسی RTL با فونت وزیرمتن و تقویم شمسی).

### فاز ۳ — اتصال گیت اجباری اشتراک، قفل سخت‌افزاری و موتور دانلود ویدیوی 8K/4K
- [ ] **مأموریت ۳.۱:** پیاده‌سازی استخراج اثرانگشت سخت‌افزاری (`HWID`)، ذخیره امن توکن در هسته سیستم‌عامل (`DPAPI` / `Keychain`)، مودال اکانت و کارت شناور `Upgrade Premium`.
- [ ] **مأموریت ۳.۲:** پیاده‌سازی سد امنیتی `DownloadGatekeeper` جهت استعلام اجباری از سرور و تأیید ریاضی امضای `Ed25519` پیش از شروع هر دانلود + مکانیسم `Heartbeat` در دانلودهای طولانی.
- [ ] **مأموریت ۳.۳:** یکپارچه‌سازی موتور ویدیو (`yt-dlp` + `ffmpeg` با اعتبارسنجی SHA-256 و قابلیت آپدیت از سرور اختصاصی) برای یوتیوب، X (توییتر)، اینستاگرام، تیک‌تاک، آپارات و ۱۰۰۰+ سایت.
- [ ] **مأموریت ۳.۴:** ساخت پنجره انتخاب کیفیت ویدیو (8K / 4K / 1440p / 1080p60 / HDR با ادغام بدون افت کیفیت تصویر و صدا)، استخراج `MP3 320kbps`، زیرنویس، پلی‌لیست و پخش آنلاین حین دانلود (`Online Watch`).

### فاز ۴ — افزونه اختصاصی مرورگر (`extension`)
- [ ] **مأموریت ۴.۱:** تولید کلید RSA مستقل افزونه و قفل کردن سرور لوکال اپ دسکتاپ صرفاً روی `Origin` افزونه اختصاصی *KFNDM*.
- [ ] **مأموریت ۴.۲:** رهگیری خودکار دانلودهای مرورگر، منوی راست‌کلیک اختصاصی و انتقال رمزنگاری‌شده کوکی‌ها برای دانلود از سایت‌های نیازمند لاگین (X، اینستاگرام، یوتیوب).
- [ ] **مأموریت ۴.۳:** دکمه شناور گرادیانی دانلود روی ویدیوهای وب، شکار استریم‌های HLS (`.m3u8`) و DASH (`.mpd`) و طراحی پاپ‌آپ هماهنگ با سیستم دیزاین تیره.

### فاز ۵ — سخت‌سازی ضدکرک (Anti-Crack)، آپدیت خودکار و پایپ‌لاین انتشار (CI/CD)
- [ ] **مأموریت ۵.۱:** کامپایل ماژول‌های لایسنس، امنیت و گیت دانلود به بایت‌کد باینری موتور V8 (`.jsc`) با استفاده از `Bytenode` و حذف سورس جاوااسکریپت آن‌ها از بیلد نهایی.
- [ ] **مأموریت ۵.۲:** اعمال فیوزهای امنیتی باینری Electron (`ASAR Integrity Validation`، بستن کامل فلگ‌های دیباگ و DevTools) و فعال‌سازی پینینگ کلید عمومی سرور جهت جلوگیری از حملات شنود (MITM).
- [ ] **مأموریت ۵.۳:** پیاده‌سازی سیستم آپدیت خودکار درون‌برنامه‌ای متصل به سرور لایسنس و پشتیبانی از آپدیت اجباری (`Force Update`).
- [ ] **مأموریت ۵.۴:** راه‌اندازی پایپ‌لاین GitHub Actions (`.github/workflows/release.yml`) برای تست و تولید خودکار فایل‌های نصبی ویندوز (`.exe`) و مک (`.dmg`) و تدوین راهنمای استقرار سرور.
